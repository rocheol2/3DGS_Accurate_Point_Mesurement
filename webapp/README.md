# 3DGS 다시점 거리 측정기 (HTML 뷰어) — 기능과 조작법

3D Gaussian Splatting(3DGS) 파일을 **브라우저에서 바로 열어**, 같은 점을 여러 각도에서 클릭해 3D 좌표와 거리를 재는 설치 없는 웹앱입니다.
측정 원리는 Deng & Qin (2026) *Accurate Point Measurement in 3DGS* 의 다시점 최소제곱 공간교회(spatial intersection)이며, 렌더링은 Spark + three.js 를 씁니다. 파일은 컴퓨터 밖으로 나가지 않습니다.

## 1. 열기

| 방법 | 어떻게 |
|---|---|
| 온라인 | https://rocheol2.github.io/3DGS_Accurate_Point_Mesurement/ |
| 더블클릭 (오프라인) | **`dist/3DGS_거리측정기_단일파일_점군직접선택.html`** (2026-09-19 최신 · 점군 보기·1클릭 직접 선택·정밀화까지 모든 기능 포함). 이전 판 `…_조작메뉴.html`, `…_방향제어.html`, `…_자동회전.html`, `…_단일파일.html` 도 남겨 둠 |
| 로컬 서버 | 저장소 루트에서 `tools/start_webapp.sh` → `http://localhost:8000/` |

`webapp/index.html` 을 직접 더블클릭하면 브라우저가 스크립트를 차단해 동작하지 않습니다(화면에 안내가 뜹니다). Chrome 권장(WebGL2).

**열 수 있는 파일**: `.ply`(3DGS 원본 `point_cloud/iteration_30000/point_cloud.ply`, SuperSplat 압축 PLY), `.spz`, `.splat`, `.ksplat`, `.sog`/`.zip`. 축척 정보 JSON(`{"units":"m"}` 또는 `{"scale_to_meters":4.2015}`)을 같이 끌어다 놓으면 자동 인식.
열 수 없는 것: `input.ply`·`points3D.ply`(일반 점군), 2DGS 원본 PLY(`scale_2` 없음), 메시·사진. 300만 가우시안/700 MB 초과 파일은 경고가 뜨며, 줄여서 쓰는 것을 권합니다.

## 2. 기본 흐름 (5분)

1. 파일을 화면에 끌어다 놓기 (또는 [📂 파일 열기], 연습은 [▶ 샘플로 체험]).
2. 휠로 잴 곳을 크게 확대 → **[● 점 측정]**(M) → 점을 한 번 클릭 → 노란 광선 1개.
3. 카메라가 자동으로 돌아가면(기본 켬) 화면 중앙 근처의 **같은 점을 다시 클릭**. 노란 점선(안내선) 위, 청록 원(추정점) 근처가 정답 위치. 5번 채우면 자동 확정.
4. **[↔ 거리 측정]**(D) 로 A·B 두 점을 재면 화면과 결과 탭에 `거리 ± 오차` 표시. 이미 잰 점 2개를 체크해 [선택 두 점 거리]도 가능.
5. 축척이 없다는 주황 배너가 뜨면 **[📏 축척 보정]** 으로 미터 단위로 전환(아래 5절).
6. **[⬇ 내보내기]** → CSV / JSON / PNG.

## 3. 구현된 기능

### 측정
- **다시점 최소제곱 교회**: N개(기본 5, 설정 2~12) 광선에 가장 가까운 점, σ₀(광선 잔차), 픽셀 잔차 RMS, 광선 최대 각도, 공분산 → 품질 배지(좋음/보통/나쁨). 거리는 두 점 공분산을 투영한 ±1σ 표시.
- **안내선(에피폴라 선)**: 첫 광선을 현재 화면에 노란 점선으로 투영. 2번째 클릭은 선에서 30 px 이내면 스냅.
- **자동 정밀 보정**: 첫 클릭 주변 무늬(25×25 px)와 정규화 상관으로 이후 클릭을 다듬음(보정량·유사도를 광선 표에 표시). 설정에서 끔 가능.
- **확대창(루페)**: 커서 옆에 확대 영역을 **별도 고해상도 렌더링**(픽셀 늘리기가 아니라 다시 그림). 배율 **2~5×**(측정 패널 선택·설정 슬라이더·`[` `]`), 크기 **소/중/대**(160/260/380 px).
- **잘못된 클릭 처리**: [↶ 마지막 취소], [✂ 최악 광선 제거], Enter 조기 확정, Esc 취소. 각도 부족(<10°)·광선 부족은 확정 차단.

### 분석 (1단계, 2026-09-19)
- **📐 분석 메뉴** (도구막대) 또는 키 **A / L / P**:
  - **∠ 각도**: 점 3개(A, 꼭짓점 B, C) → ∠ABC(°) ± 오차, 화면에 호 표시.
  - **⌒ 길이/둘레**: 점 2개 이상 순서대로 → 구간 길이 합. [✔ 완성](Enter)으로 마침.
  - **▱ 면적**: 꼭짓점 3개 이상 순서대로 → 최소제곱 평면에 투영한 다각형 면적, 함께 수평투영 면적·둘레·면 기울기·평면 잔차 RMS 표시.
- **점 재사용**: 분석 중 이미 잰 점의 화면 마커를 클릭하면 새로 재지 않고 그 점을 씁니다(거리 측정에서도 가능).
- **거리 표 확장**: 3D 거리 외에 **수평 거리, 고저차, 경사(°, %)**를 자동 표시(위 방향 축 기준).
- **오차**: 각 점의 공분산을 수치 미분으로 전파한 ±1σ. 축척이 없으면 각도만 정확하고 길이·면적은 u·u² 로 표시(⚠).
- 결과 탭 "분석" 표, CSV(analysis 섹션)·JSON 내보내기 포함. 점을 삭제하면 그 점을 쓰는 분석 항목도 지워집니다.

### 점군 보기 · 1클릭 직접 선택 (2026-09-19)
- **☁ 보기** 메뉴 또는 **Tab**: 스플랫(3DGS) ↔ **점군**(가우시안 중심점, CloudCompare 식) ↔ 겹침. 점군은 기본 **조밀 표본** 방식(가우시안마다 3D 분포에서 ×10 표본, 총 2천만 점 상한 자동 조절, 1 px)으로 원본보다 10배 조밀하고 점이 작습니다. 밀도 배수·점 크기는 측정 탭 위 빠른 조절(키 `-`/`=`)로 바꿉니다. 대안으로 **각 가우시안의 실제 크기에 비례하는 원판** 표현도 있어 표면이 빈틈 없이 보이며(설정 "가우시안 크기 배율" 0.3~3×, 최대 점 크기 기본 6 px — 점군 모드에서 측정 탭 위의 빠른 조절 또는 키 `-`/`=`), 고정 px 크기로도 바꿀 수 있습니다. 색은 파일의 sRGB 색을 그대로 재현(RGB/높이/단색).
- **1클릭 직접 선택**: 점군 화면에서는 클릭 한 번으로 점이 정해집니다(스플랫 화면에서는 설정으로 켬). 좌표 결정 방식 두 가지:
  - **앞쪽 군집 중앙값(기본·권장)**: 커서 원뿔 안 점들 중 가장 앞쪽 표면 무리의 중앙값. 흩어짐이 평균되고 1~2개짜리 잡티는 무시. σ = 군집 퍼짐.
  - **가장 가까운 점 하나**: 커서에 가장 붙은 중심점 하나. 뾰족한 특징점에 유리하지만 튄 점·잡티를 그대로 찍을 수 있음.
  - 커서 원뿔 반경(3~20 px) 조절. 설정의 **[? 설명]** 버튼과 처음 사용할 때 뜨는 안내 창에 두 방식의 차이 비교표가 있습니다.
- 직접 선택한 점은 <b>직접선택</b> 배지가 붙고(다시점 측정보다 정밀도가 낮음 — 논문이 지적한 "점군 직접 찍기"에 해당), 결과 표의 **[정밀화]**로 그 점을 중심으로 다시점 측정을 이어가 같은 점을 교체할 수 있습니다. **Shift+클릭**은 항상 다시점 광선입니다.
- 거리·각도·면적 등 모든 분석은 직접 선택 점으로도 동작하며, CSV 에 `method`(multi_ray / direct_pick_cluster / direct_pick_nearest) 열이 붙습니다.

### 카메라·시점
- **표면 인식 휠 줌**: 커서 아래 표면(가우시안 군집)을 향해 남은 거리의 12 %씩 접근, 표면을 뚫고 지나가지 않음. 궤도 중심이 그 표면에 놓여 회전이 그 점을 중심으로.
- **클릭 후 자동 회전**(켬/끔): 클릭마다 측정 중인 점을 중심으로 회전. **방향**(⟳ 오른쪽 계속 / ⟲ 왼쪽 계속 / ⇄ 좌우 번갈아 / ⇅ 위아래 번갈아), **각도**(비우면 350°÷광선 수, 기본 70°), **축**(화면 기준 / 파일 위 축) 선택. 회전 후 점은 화면 정중앙. **← → ↑ ↓** 키로 직접 회전, **R** 로 한 번 더.
- **🎮 플로팅 조작 패널**: 마우스 드래그 없이 버튼으로 회전(◀▶▲▼, 15°/클릭), 초점(◎), 확대(＋－), 이동(←→↑↓), 홈(⌂). 누르고 있으면 천천히 연속, 제목을 끌어 위치 이동, ▾ 접기, 도구막대 [🎮] 로 켜고 끔.
- **위 방향**: −Y(COLMAP 기본)/+Y/+Z 등 선택. PLY 헤더 `up axis`, 지오리퍼런싱 파일(+Z 추정)은 자동.

### 좌표·축척
- **지역·국가 좌표계 PLY 바로 열기**: 좌표가 크면(X≈285,900 m 등) 뷰어가 자동으로 원점을 옮겨 렌더링(float32 정밀도 보호). 표시·내보내기·GCP 입력 좌표는 원래 값. 오프셋은 [정보 점검]에 표시. 파일을 미리 offset 할 필요 없음.
- **축척 보정 3방법**: ① 길이 하나로(아는 길이의 양 끝 측정) ② **기준점(GCP) 좌표로**(측정한 점의 실제 X·Y·Z + 단위 m/cm/mm; 2점 → 축척, 3점 이상 → 축척+회전+이동, 이후 좌표가 실제 좌표계로 표시) ③ 축척 직접 입력(모델 1 u = 실제 몇 m). 파일별로 브라우저에 기억, 사이드카 JSON 저장·인식.
- **없는 정보는 없다고 알림**: 오류·안내 카탈로그 E01~E14(`errors.js`)를 앱 토스트·[정보 점검]·도움말이 공유. 예: E05 축척 없음(모델 단위 u 로만 표시 + 해결 3가지), E08 각도 부족, E14 큰 좌표 원점 이동.

### 결과·설정
- 결과 탭: 점 표(좌표·σ·N·품질·삭제), 거리 표, 화면 라벨. CSV(모델 단위·미터·실좌표 열), JSON(공분산·광선·오프셋 포함), PNG.
- 설정은 브라우저에 저장되어 다음 방문에 복원. 첫 방문 기능 소개 투어([? 도움말]에서 다시 보기).

## 5. 축척(미터)을 넣는 법 — 어떤 파일이 어떤 값인가

- COLMAP으로 만든 3DGS는 축척이 임의라 파일에 정보가 없습니다 → ① 또는 ②.
- `gs_ply_georef.py` 로 변환한 파일(헤더 `units: meters`)과 이 저장소의 샘플은 이미 1 u = 1 m → 입력 불필요.
- GCP 지오리퍼런싱 COLMAP(절대좌표)으로 학습한 결과(DS003 CM001 계열)는 1 u = 1 m → ③ 에 **1**.
- 로컬 좌표 COLMAP으로 학습했고 GCP Scale 을 아는 경우(DS003 CM002: 9.742857) → ③ 에 그 값.
- 확인: `head -c 3000 파일.ply | grep -a "^comment"` 로 헤더 주석 확인.
